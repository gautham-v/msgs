  • One accent, and it never marks chrome. The blue is on your own name and on the time of an unread chat — content, not furniture. Selection and focus are monochrome: the selected chat is a lighter row, the focused input is a brighter gray border. Nothing that is "where you are" is blue.
  • Timestamps sit in a right column. Every message gets a time on its first line, right-aligned to the pane edge. It doesn't compete with the text and lines up top to bottom.
  • Runs collapse. Consecutive messages from the same person show the name once; the rest are indented under it with just their time. That turns the two-line-per-message rhythm into one line.
  • No rails, no bands. Your messages aren't tinted. The selected message is the only thing with a background, and the day label is a plain gray line, not a centered band.
  • The input is a box, Grok's box. A hairline rounded border with a ❯ prompt, gray at rest and a step brighter when it has focus. The status line sits right-aligned under it in small gray, the way Grok puts Grok 4.6 · always-approve there; keys live in the footer and nowhere else.

C. Drawer. The same pane as on a wide terminal, slid over the left two-thirds of the conversation, with a brighter divider. Nothing else changes; the conversation keeps drawing behind it.
  • The cheapest to build: it is the existing pane, drawn last
  • Keeps the conversation partly in view, so arrowing through chats previews nothing but you never lose your place

what changes in the code

Mapping to slots and layout

  • Theme. accent_them and participants stop being drawn; the block rail goes, so gray_dim is left to quote borders. bg_light no longer sits behind your messages — it stays for overlays.
  • ui::message::block. The rail column and its MARGIN_LEFT become a plain 2‑column indent; the time moves from a trailing line into a right column of width 5 (HH:MM) on the first row, so wrapping happens against width − 5 − gap. Height comes from the same number as before.
  • Runs. A block whose sender matches the one above within a few minutes drops its name line and indents by the name column. Same rule the chat list already uses for "You:" in previews.
  • Chrome. The shortcuts bar and the status line merge into one row; the composer loses its border box for a top rule.
  • Keeps. Tapback chips, attachment lines, the day band, selection highlight, the light theme (same rules on a light ground) and the terminal base from earlier today — the mixes already produce this gray ladder.
